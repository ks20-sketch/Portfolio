# Portfolio

A minimal, single-column portfolio: one page, plain layout, easy to edit.

## Files
- `index.html` — all the content
- `styles.css` — all the styling, with variables at the very top

## Quick customize
1. Open `styles.css` and edit the `:root { ... }` block at the top to change
   colors, font, corner rounding, or spacing — everything else updates
   automatically.
2. Add a photo named `profile.jpg` to this folder. If it's missing, a
   plain "KC" circle is shown instead, so nothing breaks.
3. In `index.html`, edit the text directly: your name, intro, About
   paragraph, project entries and contact links.
4. To add a project, copy one `<article class="project">...</article>`
   block and edit it.
5. To add a skill, copy one `<li>` inside `.skill-list` and edit it.
6. Add your `resume.pdf` to this folder for the "Download résumé" button.
7. Replace `your.email@example.com` and the LinkedIn/GitHub links.

## Run
Open `index.html` directly in a browser.

## Deploy
Works as a static site on GitHub Pages, Netlify or Vercel — just upload
this folder.
